## 相关项目

### 🌐 GitHub 中文翻译 · Tampermonkey 脚本

一键将 GitHub 界面翻译为中文，支持导航、设置、语言列表、日期、贡献图等全部内容，采用组合翻译规则，无需逐一为每个日期写词条。

#### 安装方法

1. **安装 Tampermonkey**（如已安装可跳过）  
   - [Chrome 网上商店](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)

2. **安装脚本**  
   - 点击 [此处](https://raw.githubusercontent.com/kongbaiming5/github-translator/main/github-translator.user.js) 或访问本仓库的 [`github-translator.user.js`](https://github.com/kongbaiming5/github-translator/blob/main/github-translator.user.js) 文件，Tampermonkey 会自动弹出安装界面，点击“安装”即可。

3. **刷新 GitHub 页面**，翻译即刻生效。

#### 特点

- 🎯 覆盖 480+ 常用词条（按钮、菜单、设置、语言名称等）
- 🧩 智能组合翻译（如 `No contributions on April 1st.` → `在4月1日没有贡献。`）
- 🔄 自动适配 GitHub 的动态加载（SPA 路由切换）
- 🌐 完全本地运行，无需联网，无隐私风险
